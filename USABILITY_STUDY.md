# Syntax Voyager beginner usability study

Run the same session with five people who are learning programming and have not
used Syntax Voyager before. Do not coach them beyond the prompts below.

## Session prompts

1. Find the lesson about variables. Stop the timer when the lesson opens.
2. Explain the final values in the lesson's “Trace the journey” exercise.
3. For a program that repeats until a correct guess, choose the programming
   construct you would use and explain why.
4. Open the Flight simulator, change a program, step it, and make the mission
   pass.
5. From a lesson, identify what should be learned first.
6. Return to the galaxy, focus a coordinate, move to a connected coordinate,
   and return to the overview.
7. Start “Decode the guessing signal” and complete its first checkpoint without
   further instructions.

## Evidence to capture

For each prompt, record completion, time, wrong turns, the participant's exact
words at the point of confusion, and whether help was required. A success is
independent completion; a click path alone is not enough.

## Release decision

Fix any issue that blocks two participants or prevents one participant from
finishing. Re-test the affected prompt before closing it. The study is complete
only when all five participant rows contain real observations.
